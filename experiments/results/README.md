# Compatibility Evidence

This directory contains committed experiment output that serves as reproducible compatibility evidence.

- `mysql_connector_compat.json`: OceanBase CE 4.4.2.1 result generated by `experiments/mysql_connector_compat.py`
- Passwords are redacted by the experiment before serialization.
- Timestamps, Python versions, connector versions, target labels, exceptions, and tracebacks are intentionally retained.
- Regenerate a result only after rerunning the documented command against the named target.

Ad hoc or temporary results should be written outside the repository or reviewed before being added here.
